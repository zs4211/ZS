## Visual grammar

- US Letter portrait, 1 inch margins, one continuous section.
- White background, restrained dark-green accent (`#137333`), thin gray table rules.
- Georgia is the primary Latin font; Chinese text uses an East-Asian serif fallback.
- Cover: small green report label, short green divider, large centered title, author/date low on page.
- Running footer: short report name at left and page number at right.
- Body: green Heading 1 section titles, compact Georgia/serif body copy, modest spacing.
- Tables: light-gray header fill, green bold header text, bold row labels when useful, no decorative color blocks.

## Layout and slots

1. Cover page.
2. Document control table and purpose/abstract.
3. Methods and mathematical conventions.
4. Case/data summary and coverage results.
5. Height/BCA/range stratification with figures.
6. M-product and retrieval-candidate point diagnostics.
7. Repeated-sweep audit, limitations, scientific answers, and reproducibility appendix.

## Non-negotiable content constraints

- Never report a 3-D condition number for a 2-by-3 dual-radar observation matrix.
- Undefined dual-radar metrics are shown as `N/A`, not zero.
- M-product features are auxiliary locations, not truth.
- Document the loss of gate-to-grid contributor provenance.
- State that no solver, QC rule, filter, mesocyclone threshold, BCA threshold, or sweep selection was changed.
